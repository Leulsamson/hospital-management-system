# Domain documentation

This is a single-context Hospital Management System repository.

## Before exploring a domain

Read the root `CONTEXT.md` when it exists and review relevant architectural decisions under `docs/adr/`.
If those files do not exist, proceed using the source code, Prisma schema, API routes, and existing project documentation as the source of truth.

## Domain vocabulary

Use the project's existing terms, including patients, doctors, departments, appointments, medical records, prescriptions, medications, payments, inventory, users, roles, and audit logs.

When a new business concept or architectural decision is established, document it in `CONTEXT.md` or a dated ADR under `docs/adr/`.
